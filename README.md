# RESONANCE LAB

beatmania IIDX INFINITASのスコアCSVを手動で読み込み、分析や選曲支援に利用する非公式・個人制作のブラウザツールです。

**Version:** Prototype v0.24

## 使い方

1. 公開ページまたは `index.html` をEdge / Chromeで開きます。
2. 自分で取得したスコアCSVを読み込みます。
3. ダッシュボード、スコア検索、選曲ルーレット、履歴比較などを利用できます。

## 機能

- プロフィール表示・編集
- スコアCSVの手動取り込み
- 過去の取り込み日時と履歴の保存・比較
- 譜面・シリーズ・レベル・クリアランプによる検索と並び替え
- 譜面ごとのノーツ数・スコアレート
- 条件別選曲ルーレット
- ダッシュボードでのクリア状況・スコア分析
- JSON形式のバックアップ・復元

## 保存について（重要）

現バージョンはログインやクラウド同期に対応していません。CSVを読み込むと、そのデータはブラウザのIndexedDBに保存されます。GitHubリポジトリにユーザーのスコアCSVをアップロードする必要はありません。ブラウザデータの削除、利用する端末・ブラウザ・サイトURLの変更によって、保存済みデータが参照できなくなることがあります。定期的にJSONバックアップを出力して保管してください。

ローカルのHTMLファイルで利用していた保存データが、GitHub Pagesへ自動移行されることはありません。既存HTMLでバックアップを書き出し、公開ページ上で復元してください。

## GitHub Pagesで公開する

1. GitHubで新規リポジトリ `resonance-lab` を作成します。
2. このフォルダにある `index.html`、`README.md`、`.nojekyll`、`.gitignore` をアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source → Deploy from a branch** を選択します。
5. Branchを **main**、フォルダを **/(root)** に設定して保存します。
6. 公開されたURLをGitHub Pagesの設定画面で確認します。

例：`https://<GitHubユーザー名>.github.io/resonance-lab/`

## 公開時の注意

- **スコアCSV、バックアップJSON、個人情報、パスワードなどはGitHubにアップロードしないでください。**
- 現在のアプリには外部サイト由来の難易度・ノーツ数データがコード内に埋め込まれています。一般公開や再配布の前に、情報の出典と利用条件を確認してください。
- 本ツールは非公式であり、KONAMIとの提携・承認関係はありません。
- 現段階ではアプリ独自アカウントによるログイン機能はありません。GitHub Pages自体もアクセス制限の代替にはなりません。
- ソースコードの再利用ライセンスは未設定です。公開範囲・権利関係を確認してから選択してください。
