# RESONANCE LAB

### beatmania IIDX INFINITAS スコア管理・分析ツール

**RESONANCE LAB** は、beatmania IIDX INFINITASのプレーデータを管理・分析するために制作した、非公式のWebアプリケーションです。

公式サイトからダウンロードしたCSVファイルを読み込むことで、スコアやクリアランプの状況をさまざまな角度から確認できます。

「自分がどれくらい成長したのか知りたい」「苦手な曲を探したい」「次にプレーする曲を決めたい」

そんなときに活用できるツールを目指しています。

[![Download](https://img.shields.io/badge/Download-RESONANCE_LAB_v0.24-00B8D9?style=for-the-badge&logo=html5&logoColor=white)](https://github.com/IIDXSAIX/RESONANCE-LAB/raw/refs/heads/main/index.html)

特別なソフトのインストールやKONAMIアカウントとの連携は必要ありません。

## 主な機能

### ダッシュボード
プレーデータ全体を集計し、スコアやクリア状況を確認できます。レベルや譜面ごとの絞り込みにも対応しています。

### スコア検索
楽曲名、難易度、クリアランプ、スコアレートなどを条件に検索できます。苦手曲や未プレー曲の確認にも便利です。

### 過去の自分との比較
以前取り込んだCSVと最新データを比較し、スコアの伸び、ミス減少数、クリアランプの変化を確認できます。

### 選曲ルーレット
ランダム選曲だけでなく、AAAが近い曲、ランプ更新を狙える曲、久しぶりにプレーする曲など、目的に合わせた選曲ができます。

### データ保存・バックアップ
取り込んだデータや履歴はブラウザ内に保存されます。バックアップファイルの出力・復元にも対応しています。

## 使い方

1. 上のダウンロードボタンからHTMLファイルを入手します。
2. ダウンロードした `index.html` をPCのブラウザで開きます。
3. beatmania IIDX INFINITAS公式サイトから自分のスコアCSVをダウンロードします。
4. RESONANCE LABでCSVを読み込みます。
5. ダッシュボードやスコア検索などの機能をご利用ください。

CSVを新しく取り込むことで、過去の記録との比較もできます。

## ご利用上の注意

- 現在は試作版（v0.24）です。不具合や仕様変更が発生する可能性があります。
- データの取得は手動CSV取り込み方式です。公式サイトとの自動連携はありません。
- データは利用中のブラウザに保存されます。別のブラウザや端末との自動同期には対応していません。
- ブラウザのデータ削除などで記録が失われる可能性があります。定期的なバックアップをおすすめします。
- 本ツールは個人制作の非公式アプリであり、KONAMIおよびbeatmania IIDXの公式サービスとは関係ありません。
