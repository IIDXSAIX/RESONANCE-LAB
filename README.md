# RESONANCE LAB

### beatmania IIDX INFINITAS Score Management & Analysis Tool

**RESONANCE LAB** は、beatmania IIDX INFINITASのスコア管理・分析を目的とした非公式Webアプリケーションです。

公式サイトからダウンロードしたCSVファイルを読み込むことで、プレーデータをさまざまな角度から確認・分析できます。

スコアの成長を振り返る、苦手な楽曲を見つける、次にプレーする曲を決める。

**日々のINFINITASを、より楽しく快適にするためのツール**を目指しています。

## FEATURES

### Dashboard
プレー状況をまとめて確認できるダッシュボード機能です。

- クリアランプの分布
- スコア・DJランクの集計
- 難易度別・シリーズ別の分析
- プレイヤープロフィール表示

### Score Search
プレーデータを条件に合わせて検索・整理できます。

- 楽曲名・難易度・譜面別検索
- クリアランプによる絞り込み
- スコアレート・プレー回数などの並べ替え
- 未プレー楽曲の確認

### Personal Best Comparison
過去のCSVデータと現在のデータを比較し、自分自身の成長を確認できます。

- EXスコアの変化
- ミス減少数
- クリアランプの変化
- 過去の記録との比較

### Music Roulette
プレーする楽曲を条件に合わせて選曲する機能です。

- ランダム選曲
- AAA達成が近い楽曲
- ランプ更新が狙える楽曲
- 苦手な楽曲
- 長期間プレーしていない楽曲

### Data Management
CSVファイルの取り込みと履歴管理に対応しています。

- CSVファイルの手動取り込み
- 過去の取り込み履歴の保存
- JSON形式でのバックアップ
- バックアップデータの復元

## GETTING STARTED

**STEP 1 — Download**

上記のDOWNLOADボタンからHTMLファイルをダウンロードします。

**STEP 2 — Launch**

ダウンロードした `index.html` をMicrosoft EdgeやGoogle Chromeなどのブラウザで開きます。

**STEP 3 — Export CSV**

beatmania IIDX INFINITAS公式サイトから、ご自身のスコアCSVファイルをダウンロードします。

**STEP 4 — Import**

RESONANCE LABでCSVファイルを取り込みます。

取り込みが完了すると、各種分析機能をご利用いただけます。
